# v3.10 - Valoare orientativa

- Pretul explicit, unic si plauzibil extras din anunt este expus ca `askingPriceEur`.
- Reper central: pret anunt minus 5.000 EUR pentru preturi sub 100.000 EUR, minus 10.000 EUR altfel.
- Limite: +/-18% fata de reperul central.
- Graficul afiseaza pretul din anunt, reperul central si limitele, alaturi de istoricul indicelui.
- In lipsa unui pret explicit neambiguu, ramane reperul bazat pe suprafata si indice.
- Aceasta este o regula de prezentare solicitata de utilizator, nu o evaluare de piata independenta.
